# Corpafly Theme

Design, brand book and Shopify theme for corpafly.com.

| File | Purpose |
|---|---|
| `BRIEF.md` | Facts about the brand, products, buyers and store |
| `CLAUDE.md` | Rules and the phased process (loaded automatically by Claude Code) |
| `PROMPT.md` | The first message to paste into Claude Code |
| `brand/assets/` | Real brand files (logo, thank-you card, product video) |

## How to run it

1. Put the brand files in `brand/assets/` (see the README there).
2. Open Claude Code on the web, pick this repo, choose the strongest model available.
3. Paste the text from `PROMPT.md` and send.
4. It stops at Gate 1 with three homepage directions to choose from.

## Where things are (Gate 1)

- **Start here:** [`GATE-1.md`](GATE-1.md): the research in ten lines, the three directions and what is needed to move on.
- **Hub page:** https://muneebhash.github.io/Corpafly-theme/ (directions, brand book, logo set, research).
- `research/`: five research streams and `REPORT.md`. `brand/`: brand book, SVG logo set, asset inventory. `prototypes/`: the three homepage directions, their shared foundation and screenshots. `DECISIONS.md`: every decision and assumption.

## Viewing the prototypes

Turn on GitHub Pages once: repo **Settings > Pages > Deploy from a branch > `main` / root > Save**. Prototypes then open at
`https://muneebhash.github.io/Corpafly-theme/prototypes/direction-a/` (and `-b`, `-c`).
