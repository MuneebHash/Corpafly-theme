# Direction C: Order Desk

**The idea.** Most Corpafly buyers arrive knowing what they need, so the homepage is an order desk, not a brochure. Pick a type, set colors and pack counts, watch the price per lanyard update, and check out from the first screen.

**What is glass**
- The header, which carries a running cart total.
- The receipt over the live preview, the main glass moment: the hanging straps blur through it.
- The phone summary bar, the cart drawer and the finder's suggested order on desktop.

**What moves**
- Prices roll digit by digit (240 ms).
- Every color the pack comes in hangs as a faint ghost; an ordered color drops onto its peg and firms up (320 ms). Receipt lines drop into place.
- The finder's answer rises in, and the break-away clasp springs open when pulled.
- On load, only the desk rises (480 ms). Under reduced motion, values change instantly and the pull demo becomes a Before / After toggle.

**Why it fits Corpafly buyers**
Office managers reorder the same thing: Buy again and the order link make that one step. Teachers and event teams color-code, with the price per lanyard always in view. Travelers want one small pack: the Travel row loads it in one tap.

**Type.** Hanken Grotesk throughout: tabular numerals that align and roll cleanly, and a plain zero, so prices read as prices, not code.
